# Captions for Parts 1–6

## Part 1

Let's learn how to build an AI Agent from scratch in Python.

In Part 1, we'll run a language model on our computer, connect it to Python through localhost, send it a message, and print the response. This gives us the first piece of our agent: a Python program that can communicate with the model.

## Part 2

Let's learn how to build an AI Agent from scratch in Python.

In Part 2, we'll give the model its first tool. We'll create a Python function that reads the computer's current time, let the model request that function, and return the result so it can answer with real information from the computer.

## Part 3

Let's learn how to build an AI Agent from scratch in Python.

In Part 3, we'll turn one tool request into an agent loop. Python will keep sending results back to the model, and the model will keep choosing what to do next until it returns a final answer.

## Part 4

Let's learn how to build an AI Agent from scratch in Python.

In Part 4, we'll give our agent multiple tools. The model will choose the tool it needs, Python will match that request to an approved function, and the result will return to the model so it can continue.

## Part 5

Let's learn how to build an AI Agent from scratch in Python.

In Part 5, we'll make the agent recover from errors. Python will validate every tool request, return failures as useful information, and stop the loop safely if the model keeps working for too long.

## Part 6

Let's learn how to build an AI Agent from scratch in Python.

In Part 6, we'll add permissions and limits. The agent will be able to work with files inside one controlled folder, while Python checks every path, asks before writing anything, and limits how many actions can run.
