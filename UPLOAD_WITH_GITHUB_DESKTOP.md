# Upload This Course With GitHub Desktop

## 1. Extract the ZIP

Right-click the downloaded ZIP and extract it. Keep the complete `ai-agent-from-scratch` folder together.

Open GitHub Desktop and sign in to the GitHub account where you want the course to appear.

## 2. Turn the folder into a repository

1. Open GitHub Desktop.
2. Select **File > Add Local Repository**.
3. Choose the extracted `ai-agent-from-scratch` folder.
4. GitHub Desktop will say that the folder is not a Git repository. Click **create a repository**.
5. Keep the name `ai-agent-from-scratch`. The folder already contains a README, `.gitignore`, and license, so do not ask GitHub Desktop to add replacements.
6. Click **Create Repository**.

If the files appear in the **Changes** tab, enter `Add the complete course` as the summary and click **Commit to main** before publishing.

## 3. Publish it

1. Click **Publish repository** in the top bar.
2. Use this description: `Build a local AI agent from scratch in six beginner-friendly parts.`
3. Uncheck **Keep this code private** if you want viewers to access the course.
4. Click **Publish Repository**.

Use **Repository > View on GitHub** to confirm that all six `parts` folders and the main README are visible.

## Optional: publish the interactive dashboard

1. Open the repository on GitHub.com.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main`, choose `/ (root)`, and save.
5. GitHub may take a few minutes to publish the site. The dashboard will be available at:

```text
https://YOUR-USERNAME.github.io/ai-agent-from-scratch/course/
```

GitHub's official references: [create and publish with GitHub Desktop](https://docs.github.com/en/desktop/overview/creating-your-first-repository-using-github-desktop) and [configure a GitHub Pages publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
